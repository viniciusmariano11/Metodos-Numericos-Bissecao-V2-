## Como executar
### Pré-requisitos

- Navegador moderno (Google Chrome, Microsoft Edge ou Mozilla Firefox)
- Visual Studio Code (opcional)
- Extensão **Live Server** (recomendado)

### Executando o projeto

1. Clone este repositório:

```bash
git clone https://github.com/SEU-USUARIO/Bissecao-V2.git
```

2. Abra a pasta do projeto no Visual Studio Code.

3. Clique com o botão direito no arquivo `index.html`.

4. Selecione **Open with Live Server**.

5. O navegador será aberto automaticamente com a aplicação em execução.

> Também é possível abrir o arquivo `index.html` diretamente no navegador, porém utilizar o Live Server é recomendado para evitar possíveis restrições relacionadas ao carregamento de arquivos.
